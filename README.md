# Super EQ (Android, Kotlin + Compose)

Build:
1. Android Studio (Koala+) -> Open this folder -> Sync Gradle
2. Run on a real phone (emulators have no effect engine)
3. APK: Build > Build Bundle(s)/APK(s) > Build APK(s)  -> app/build/outputs/apk/debug/

First run: tap permission buttons on the EQ tab, then enable Notification Access for "Super EQ Now Playing".
